# homebrew-btrack

Homebrew tap for [btrack](https://github.com/tolgazorlu/btrack), a CLI time tracker.

## About
This repository hosts the Homebrew formula (`btrack.rb`) used to install btrack via `brew`. The formula is regenerated and committed automatically by [GoReleaser](https://goreleaser.com/) on every btrack release, do not edit it by hand.

## Getting started
```bash
brew tap tolgazorlu/btrack
brew install btrack
```

## Related projects
- [btrack](https://github.com/tolgazorlu/btrack): the CLI tool this tap distributes

## Status
Active, updated automatically with each btrack release.
